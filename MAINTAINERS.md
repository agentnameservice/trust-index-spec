# Maintainers

The [trust-index-spec-maintainers team](https://github.com/orgs/agentnameservice/teams/trust-index-spec-maintainers)
maintains this repository. The [trust-index-spec-reviewers team](https://github.com/orgs/agentnameservice/teams/trust-index-spec-reviewers)
provides reviews. Current membership and GitHub access are recorded in
[the organization team configuration](https://github.com/agentnameservice/.github/blob/main/peribolos.yml).
Propose membership changes there through a reviewed pull request.
